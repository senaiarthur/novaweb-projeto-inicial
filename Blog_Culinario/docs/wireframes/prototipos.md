# Documentação dos Protótipos

## 1. Identificação

**Projeto:** Sistema Administrativo Corporativo

**Agência:** NovaWeb Solutions

**Ferramenta:** Figma

**Tipo de prototipagem:** Alta fidelidade

## 2. Protótipos desenvolvidos

O projeto contempla três interfaces principais, cada uma desenvolvida nas versões Desktop e Mobile.

### 2.1 Tela de Autenticação (Login)

**Versões:** Desktop e Mobile.

**Finalidade:** permitir que os colaboradores acessem o sistema por meio de um formulário de autenticação.

### 2.2 Perfil do Usuário

**Versões:** Desktop e Mobile.

**Finalidade:** apresentar os dados cadastrais e profissionais do colaborador de maneira organizada.

### 2.3 Consulta de Dados

**Versões:** Desktop e Mobile.

**Finalidade:** permitir a visualização de dados operacionais por meio de uma tabela e um campo de pesquisa.

## 5. Finalidade da documentação

Os protótipos servem como referência visual para a futura implementação em HTML, CSS e JavaScript, orientando a estrutura dos componentes, a organização das informações e a adaptação das interfaces para diferentes tamanhos de tela.
