# Recursos Gráficos (Assets)

## 1. Objetivo

Este diretório armazena os recursos gráficos utilizados no Sistema Administrativo Corporativo da NovaWeb Solutions.

Os arquivos são organizados para facilitar sua localização, reutilização e integração durante o desenvolvimento das interfaces.

## 2. Organização

### images/

Armazena imagens rasterizadas utilizadas no sistema, como fotografias, imagens de perfil e outros recursos visuais.

Formato preferencial: WebP.

### icons/

Armazena ícones e elementos gráficos vetoriais utilizados nas interfaces.

Formato preferencial: SVG.

## 3. Otimização

As imagens deverão passar por um processo de compressão e redimensionamento antes de serem adicionadas ao projeto.

Ferramenta prevista: Squoosh.

Boas práticas:

- Evitar imagens com resolução excessiva.
- Utilizar WebP para fotografias.
- Priorizar SVG para ícones.
- Verificar a qualidade após a compressão.
- Utilizar nomes de arquivos descritivos.
- Evitar arquivos duplicados.

## 4. Licenciamento

Imagens e ícones obtidos de fontes externas deverão respeitar as respectivas licenças e condições de utilização.

## 5. Status

Os recursos gráficos serão adicionados e organizados conforme as necessidades identificadas nos protótipos.
